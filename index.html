Architecture

How the toolkit works.

The toolkit uses PowerShell as the automation layer between Microsoft 365 services, Graph APIs, governance logic, and evidence outputs.

Microsoft 365 E3/E5 Lab TenantEntra ID, Intune, Defender, Exchange Online, SharePoint, Conditional Access
↓
Microsoft Graph + Security APIsUser, group, role, device, risk, app registration, and service principal data
↓
PowerShell Automation Layer30+ scripts for audit, governance, reporting, and operational triage
↓
Risk & Governance LogicCritical / high / medium classifications, compliance states, license waste, OAuth risk
↓
Evidence OutputsCSV reports, TXT summaries, screenshots, README documentation, and GitHub Pages

Operational coverage

  • Identity governance: users, groups, admin roles, MFA, guest users, risky users.
  • Endpoint governance: Company Portal enrollment, Intune inventory, ownership, and compliance-state review.
  • Access governance: Conditional Access, BYOD policy checks, web-only access restrictions.
  • Messaging security: external forwarding, inbox rules, transport rules, anti-spam policies.
  • Application security: app registrations, service principals, OAuth grants, credential expiry.
  • Security triage: early evidence package for suspicious account activity and escalation.
  • Data protection: DLP simulation, compliance improvement review, insider-risk policy design, sensitivity labels, and retention.
